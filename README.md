# Salamander Species Classification via Electronic Nose

ML-based species classification of two endangered endemic salamander 
species using electronic nose odor data.

## Overview
Developed a machine learning pipeline to determine whether two closely 
related, endangered salamander species endemic to Turkey —
*Lyciasalamandra flavimembris* and *Lyciasalamandra fazilae* — can be 
distinguished through pheromone scent signatures alone.

## Dataset
- 576 odor samples collected via electronic nose in natural habitat
- Species are IUCN "Endangered" (EN) category

## Methods
Compared four classification models:
- Artificial Neural Networks
- Decision Trees
- Logistic Regression
- Support Vector Machines (SVM)

**Best accuracy: 86.67%**

## Key Finding
Scent-based species discrimination is achievable through AI — 
a novel, non-invasive alternative to traditional morphological 
and genetic classification methods.
